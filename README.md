# 천 년의 빚 (가칭)

**▶ 바로 플레이: https://sryanius.github.io/millennium-debt/** (PC 브라우저·폰 가로 화면)

1990년대 PC 게임 《하이리워드》의 진행 방식(실시간 시계, 매주 빚 상환, 여섯 부대를 굴려 돈 버는 다섯 길)을 《균열의 시대》 세계관(제국력 1000년, 베르단 대륙) 위에 올린 도트풍 용병단 경영 게임입니다. 아버지가 남긴 빚 1,000만 골을 갚으면 엔딩입니다.

## 조작
- 거점을 누르면 이동하거나, 성 안에서는 거점 명령(교역소·상점·술집·병원·게시판·건축·편성)을 엽니다.
- 화면 아래 1~6번이 부대장입니다. 누르면 선택, 두 번 누르면 지도가 그 부대로 갑니다.
- 지도는 끌어서 움직이고 휠(폰은 두 손가락)로 확대합니다. 왼쪽 위 축소 지도와 "세계 지도"로 지역을 옮깁니다.
- 오른쪽 위 ▶ 로 속도(정지·1·2·4배), ⚑ 부대 목록, ⚙ 저장·불러오기. 창을 열면 시간이 멈춥니다.
- 매달 7·14·21·28일이 상환일입니다. 돈이 모자라면 집행관 호위대와 싸우거나 가산금을 받아들입니다.
- 전투 중 전장을 누르면 멈추고 명령(대열·퇴각)을 내립니다.

## 개발
```
npm install
npm run dev        # http://localhost:5196  (?new = 저장 무시하고 새로 시작, ?bg = 숨은 탭에서도 진행)
npm test           # 규칙 테스트(Vitest)
npm run build      # dist/  — main 에 올리면 GitHub Actions 가 Pages 로 배포
```
- `src/core/` 규칙(Phaser 무관), `src/game/` 화면(Phaser 4), `src/data/world/` 세계 데이터 사본, `public/art/` 도트 그림.
- `tools/` 의 그림 생성 스크립트(로컬 ComfyUI·도트 변환)는 원본 작업 폴더(《균열의 시대》 자료가 있는 곳)에서 돌린다. 게임을 빌드·플레이하는 데는 필요 없다.

## 자세한 진행 기록
- 브라우저 창: `.claude/launch.json`의 `mercenary` 항목(포트 5196).
- `?bg`를 붙이면(`http://localhost:5196/?bg`) 탭이 가려져 있어도 게임 루프가 1초 간격으로 돈다. 자동 검증용이며 사람이 플레이할 땐 붙이지 않는다.
- 테스트: `npm test` (Vitest, 규칙 코어 45건). 타입 검사: `npx tsc --noEmit`. 배포 빌드: `npm run build`.
- `?new` 를 붙이면 저장을 무시하고 새로 시작.

## 1단계에서 되는 것
- 실시간 시계(속도 ⏸/1/2/4, 창을 열면 자동 정지), 날짜·다음 상환일 표시, 반원 시계.
- 부대 6개를 거점 클릭 → "이동 (n일)"로 도로 그래프 위에서 따로 움직인다. 드워프·엘프·군도 지역은 진입 불가.
- 상환일 자동 차감 → 집행관 대화(추가 상환 금액 목록 5,000~5,000,000). 돈이 모자라면 가산금 100,000.
- 성 안 거점 명령 9항목(원작 그대로). 열리는 것: 교역소 · 민사게시판 · 상점(목록만) · 군사게시판(안내만). 나머지는 2단계.
- 교역소 표(상품·판값·재고·산값·소유)와 사기/팔기, 민사 게시판(일·목적지·기간·의뢰인·보수·수락)과 도착 시 자동 배달·보수.
- 세계 지도 ↔ 지역 지도(축소 지도 클릭·"세계 지도" 버튼·휠·두 손가락), 장부·소식·부대·시스템 창, 자동 저장(30초, 탭 숨김).
- 완납하면 엔딩 카드(돈 내역 7줄, 가장 많이 번 길).

## 2단계에서 되는 것 (2026-10-29)
- **계약소**(상점에 감 → 계약소): 직업·HP·급료·능력치·고용비 표, 우측 부대원 격자, 해고 = 고용비 환급. 9직업(`src/core/jobs.ts`), 마법병은 상아탑·에스펠·엘프 삼림, 철갑보병은 북부만.
- **무기점·방패점·약국**: 좌 점주 / 중 품목 / 우 부대원 격자. 사면 바로 장착, 쓰던 것은 반값. "장비를 판다". 성 규모가 단계 상한.
- **부대원 편성**: 6열 × 9칸 격자, 같은 거점의 부대끼리 이동. 대열 8종·태세·공격 방식 설정. **병기 편성**: 대원별 장비 보기·되팔기.
- **군사 게시판**: 토벌 의뢰(작전 내용·규모·의뢰인·보수, 기한 없음). 수락하면 지도에 빨간 깃발 도적단. 그 거점에 도착하면 바로 교전.
- **전투**(`src/core/battle.ts` + `BattleScene`): 지도 위 타원 전장, 좌상 적 패널·우상 아군 패널(이름·HP), 대열대로 서서 실시간 자동 교전(공격 섬광·피격 표시). 전장 클릭 → 멈춤 + 전투명령/전체퇴각/개별퇴각/전투재개. 전투명령 → 대열 8종 + 백병전/사격. 대원 클릭 → 정보 + 후퇴(적도 클릭 가능). 부대장이 쓰러지면 전원 퇴각. 결과 창(전사·전리품·전과).
- **집행관 호위대**: 상환일에 돈이 모자라면 "호위대와 싸운다 / 가산금을 받아들인다". 이기면 이번 주 유예(가산금 없음), 호위대 단계 +1(최대 5). 지면 가산금 100,000.
- **급료·피로·병원**: 매달 1일 급료, 못 주면 장비 든 대원이 도망. 행군 피로 +3/일, 성에서 쉬면 −6. 병원은 HP·피로를 돈 받고 회복.
- 저장 형식 v2(`?new` 로 저장 무시하고 새로 시작).

## 3단계에서 되는 것 (2026-10-29)
- **술집**: 소문(이 지역에서 가장 남는 교역 한 줄) · 공연(공연력 = P 합계 + 악기·드레스, 성 규모 × 18 미만이면 실패 + 위약금, 3일에 한 번) · 임무(그 거점의 대형 이벤트 입구).
- **건축 길드**: 상한 요새 보수(내구 1당 작업 6·보수 110)와 성벽 증축. 부대가 현장에 머물며 건축력/일 만큼 진행, 완공 시 건축 수입.
- **도구점**: 장부·저울(T), 류트·드레스(P), 해머·곡괭이(B).
- **잿빛 교단**: 점령지(도른·하이펠트·모르덴·그레이홀로 + 요충지 5)는 통과 불가. 점령 성에서 전투단이 나와 가까운 요새를 포위, 하루 8씩 내구를 깎아 0이면 함락(요새 보고). 부대를 점령지로 보내면 **공성전**(성벽 유닛: 공성 방식이면 ×3, 성벽이 선 동안 수비대 방어 ×1.5). 탈환 보수 성 150,000 / 요충지 40,000.
- **떠돌이 도적단**(8일마다, 최대 3)과 **총호송 매복**. 소식 창 → 요새 보고.

## 4·5단계에서 되는 것 (2026-10-29)
- **진입 해제**: 드워프 산문(두린·드워프가 철산 대문에 오면 통행세 5,000) · 엘프 경계(혼혈·엘프가 있어야 숲 입장, 그 뒤로도 규칙 유지) · 군도 항로(항구에서 선금 8,000).
- **배편**: 가까운 항구끼리 점선 항로, 뱃삯 1인당 40. 사막(R05)은 행군 피로 2배.
- **배경 역사**(막을 수 없음): 1000.2 봉기 · 1000.3 토벌령(검은 창 경쟁 시작) · 1001.6 오토의 도른 탈환 · 1002.6 교단 와해 · 1003.1 폐위 시도 · 1004.1 제도 약탈(아르덴 교역소 폐쇄, 피난민 호송 보수 ×3).
- **검은 창**: 토벌령 뒤 고수익 의뢰 선점(브록이 있으면 덜함), 술집에서 공동 작전 제안(창병 3 지원, 보수 40%).
- **대형 이벤트 10**(GDD §9 전부, `src/core/events.ts`): 엘프 숲 부대 제한 · 이졸데 호송(단원 합류) · 유적 지도와 인장 조각 3 · 저주받은 골렘 · 아델라 성지 세탁물(여성 부대장) · 라엘린 궁술 대회 · 고원 사절(환대/구출) · 결계 부품 · 황태후의 밀서(근위대 3진, 250만) · 그레이홀로 상자(500만 / 인장으로 열면 1,000만).
- **엔딩 카드**: 결산 1장 + 부대장 6장(엔딩 종류별 후일담 30개) + 시.
- 헤드리스: `game.autoEvents = true` 면 이벤트를 자동으로 넘긴다(테스트·밸런스 시뮬).
